# 性能状态

MacinMeter 0.2.0 暂不发布性能承诺。

此前记录在这里的数字来自已经删除的 0.1.x 包级并行、文件级并行、SIMD 和
FFmpeg/DSD 路径，不能代表 M0 架构，也不能作为正确性或吞吐承诺。

M0 有意先建立安全标量、全串行的基线。新的 benchmark suite 只会在以下条件满足后
加入：

- workspace 契约和面向参考研究的结果语义已经稳定；
- 数据集、命令、环境与二进制 hash 均被记录；
- 计时能区分发现、解码、分析和渲染；
- 必要时峰值内存覆盖完整进程树；
- 对比采用随机或交错顺序，不依赖固定热身次序。

后续优化会优先考虑由 application 统一管理、具有共享资源预算的单一文件级并行轴。
本文档不暗示包级并行、SIMD 或外部解码进程会恢复。
